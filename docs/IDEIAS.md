# Ideias futuras do LanCam

Estas são propostas, não recursos prontos nem compromissos de implementação. A prioridade atual é validar a transmissão Android → Windows do [roteiro de testes](TESTES.md).

| Ideia | Benefício | Antes de começar |
| --- | --- | --- |
| Descoberta automática do celular | Evitar digitar o IP | Confirmar conexão manual e comportamento da rede |
| Mensagens de conexão mais claras | Facilitar o diagnóstico pelo usuário | Observar erros reais nos primeiros testes |
| Webcam virtual no Windows | Usar a imagem em aplicativos que aceitam webcam | Avaliar integração, instalação e manutenção |
| Conexão por USB | Alternativa ao Wi-Fi | Definir fluxo de instalação e conexão simples |
| Áudio/microfone | Levar som junto da imagem | Definir sincronização e destino do áudio |
| Vários celulares | Alternar entre câmeras | Validar estabilidade com uma câmera primeiro |

## Como escolher a próxima ideia

Na conversa Principal, definir o problema que ela resolve, o mínimo necessário para funcionar e como o usuário vai testar. Promover uma ideia por vez para trabalho ativo e atualizar o estado do projeto ao concluir.
